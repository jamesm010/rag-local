# Project Brief

**Project Name:** RAG Local (Placeholder)

**Goals:**
- Build a local Retrieval-Augmented Generation (RAG) application.
- Implement document ingestion and vector storage using Weaviate.
- Provide an API for querying the RAG system.

**Scope:**
- Initial setup of Next.js project.
- Weaviate integration (client setup, document upload API).
- (Future) Query endpoint implementation.
- (Future) Basic UI for interaction.

**Key Features:**
- Document upload endpoint.
- Vector search capability (via Weaviate).

**Non-Goals:**
- Production-ready deployment pipeline.
- Complex user authentication.
- Advanced UI features.
