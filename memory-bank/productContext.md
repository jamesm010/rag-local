# Product Context

**Problem:** Developers need a way to easily ingest documents into a local vector store for Retrieval-Augmented Generation (RAG) development and testing.

**Solution:** A Next.js application providing:
- A basic API endpoint for uploading documents to a Weaviate instance.
- Standard tooling (TypeScript, Tailwind, Shadcn) for further development.

**Users:** Developers building or experimenting with RAG applications locally.
